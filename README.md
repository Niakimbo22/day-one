# Day One

Widget Android de comptes à rebours de sorties de jeux vidéo (style Nothing).

**Installer :** télécharge [DayOne.apk](https://github.com/Niakimbo22/day-one/raw/main/DayOne.apk), ouvre-le, autorise les sources inconnues si Android le demande. Si le téléchargement bloque, ouvre `DayOne.apk` dans la liste des fichiers ci-dessus puis « Download raw file ».

Ensuite : appui long sur l'écran d'accueil, Widgets, Day One. Les mises à jour se font depuis l'app (bouton MAJ).
